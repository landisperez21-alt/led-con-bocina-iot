## ◈ 01. SOBRE EL PROYECTO

**LED con Bocina** es un proyecto de integración tecnológica desarrollado con Python y Django, orientado al control de componentes electrónicos mediante una aplicación web.

La propuesta combina el desarrollo de software con conceptos de Internet de las Cosas (IoT), utilizando una estructura web para gestionar las funciones del sistema electrónico.

## ◈ 04. INSTALACIÓN

Clona el repositorio:

```bash
git clone https://github.com/landisperez21-alt/led-con-bocina-iot.git
```

Ingresa al directorio del proyecto:

```bash
cd led_con_bocina/led_bocina_iot
```

Crea un entorno virtual:

```bash
python -m venv venv
```

Actívalo en Windows:

```bash
venv\Scripts\activate
```

Instala las dependencias:

```bash
pip install -r requirement.txt
```

Ejecuta las migraciones:

```bash
python manage.py migrate
```

Inicia el servidor:

```bash
python manage.py runserver
```

Abre el navegador:

```text
http://127.0.0.1:8000/
```
